# Gustavo Allify Portfolio

Portfolio profissional estático publicado com GitHub Pages.

## Estrutura

- `index.html`: página principal do portfolio.
- `assets/css/styles.css`: estilos globais.
- `assets/js/main.js`: interações leves.
- `assets/images/`: imagens e ícones.
- `assets/files/`: currículo e outros arquivos para download.
- `projects/`: páginas estáticas de projetos incorporadas por iframe.

## Publicação

O deploy está configurado em `.github/workflows/pages.yml`.

No GitHub, habilite Pages em `Settings > Pages` e selecione `GitHub Actions` como fonte de publicação.
